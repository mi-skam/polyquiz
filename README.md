# Polyamory Style Assessment

A comprehensive quiz to help you discover your polyamory style based on the frameworks discussed in "The Ethical Slut" by Janet Hardy and Dossie Easton.

## 🌐 Live Demo

**[Take the Quiz →](https://mi-skam.github.io/polyquiz/)**

## ✨ Features

- **50 Questions** covering all aspects of polyamorous relationships
- **8 Assessment Categories**:
  - Hierarchical vs Non-Hierarchical
  - Kitchen Table vs Parallel
  - Solo Polyamory
  - Relationship Escalator preferences
  - Fluid Bonding vs Safer Sex approaches
- **Bilingual Support**: German and English
- **Dark Mode**: Auto-detection of system preference with manual toggle
- **Detailed Results**: Comprehensive interpretation and guidance
- **Mobile Responsive**: Works on all devices

## 🎯 Assessment Categories

### Relationship Structure
- **Hierarchical Polyamory**: Clear relationship hierarchies with primary partnerships
- **Non-Hierarchical Polyamory**: Equal treatment of all relationships
- **Kitchen Table Polyamory**: Interconnected relationships and community
- **Parallel Polyamory**: Independent relationships with minimal overlap
- **Solo Polyamory**: Prioritizing personal autonomy and independence

### Bonding & Commitment
- **Relationship Escalator**: Traditional relationship milestones
- **Fluid Bonding**: Intimate physical and emotional bonds
- **Safer Sex Focus**: Safety protocols and protective measures

## 🛠 Technology Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS with dark mode support
- **Build Tool**: Vite
- **Runtime**: Deno 2.x
- **Deployment**: GitHub Pages
- **Version Control**: Git-based semantic versioning

## 🌙 Dark Mode

The application automatically detects your system's dark mode preference and switches accordingly. You can also manually toggle between:
- ☀️ Light mode
- 🌙 Dark mode
- 🔄 Auto (follows system preference)
